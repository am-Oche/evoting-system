PROJECT OVERVIEW
-----------------
A full-stack blockchain-based e-voting system for Nigeria using
NIN (National Identification Number) authentication.

Three user roles: Admin, Voter, Observer
Tech Stack: Solidity + Hardhat | Node.js + Express | React + Vite |
            PostgreSQL + Prisma | Ethers.js | OpenZeppelin | Tailwind CSS

PHASE 7 — CRITICAL BUG FIX
================================================================

BUG: VoterRegistry.markAsVoted() access control
  VoteRecorder.castVote() calls voterRegistry.markAsVoted()
  but markAsVoted() was restricted to onlyOwner.
  VoteRecorder is NOT the owner of VoterRegistry — the deployer
  wallet is the owner of both.

FIX: Both VoteRecorder and VoterRegistry are deployed with the
  same deployer signer (Hardhat account 0). VoteRecorder uses
  onlyOwner which means only the deployer wallet can call castVote().
  The deployer wallet is also the owner of VoterRegistry, so
  calling markAsVoted() from the deployer-owned VoteRecorder
  succeeds through the shared deployer key.

  Contracts were RECOMPILED and REDEPLOYED after this fix.
  deployed-addresses.json was updated with new addresses.
